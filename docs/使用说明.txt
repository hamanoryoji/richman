RichOnline 本地一键端
====================

【怎么启动】
双击本目录下的  启动.bat
它会先检查服务端是否在运行，没运行就启动，然后启动客户端。
客户端登录界面出现后，输入用户名和密码即可。

【账号规则】
- 服务端已开启自动注册：输入一个"库里没有的用户名"+ 任意密码，会自动建号并直接进入。
- 一个用户名 = 一个角色（默认 6 级、金豆 10000）。
- 密码忘了就换个新用户名，不用纠结。
- 首次使用没有任何预置账号，随便起一个即可。

【数据在哪 / 怎么备份】
server\data\richonline.sqlite3   ← 账号、角色、仓库、邮件全在这一个文件
server\data\lobby-bootstrap.json ← 网络端口、频道、资源路径配置
备份就直接复制 sqlite3 文件（关服后复制最稳）。
注意：本覆盖包里的 richonline.sqlite3 是空库（已迁移到 2021 日期格式）。如果覆盖到已有存档的目录，
先备份 server\data\richonline.sqlite3，再用包里的空库启动，否则角色会丢。

【端口】
18600 大厅 / 18602 游戏 / 18680 服务器列表 HTTP
全部只绑 127.0.0.1，不对外网开放，断网也能玩。

【已知限制（作者尚未完成的部分）】
- 已修复：进入地图时卡死。新版客户端用 opcode 1 表示"地图就绪"，而服务端只认 opcode 0，导致永远等不到棋盘数据；现在两种都接受。
- 只有 BS_1_1 这张 BOSS 图能正常开局，其他地图会被服务端拒绝。
- gameReady 仍为 false，完整 BOSS 玩法、宠物等未实现。
- 商城已启用：客户端打了日期补丁（inventory_date_epoch=2021，显示年份 2021–2036），数据库已迁移到 richonline-inventory-date-2021-v1，bootstrap 使用 compat_2021_v1。不要再改回 original_2005，否则购买会被拒。
- 游戏内"注册"按钮走的是网页接口，本地没实现，会失败——用登录框直接注册即可。

【GM 工具】
双击 GM工具.bat 打开（需要服务端正在运行）。
- 列表选中角色 → 右侧改「等级 / 经验 / 金豆 / 金币 / 银行存款 / VIP / 胜场 / 负场」→ 点「应用修改」
- 等级上限 20，VIP 上限 3；商店部分服装要求 7 级才能穿
- 改完必须重新登录（退出频道再进，或退游戏重开）才生效，服务端缓存了角色数据
- 同一界面还有：新建账号、备份数据库、设置公告、重载脚本（改完 Lua 不用重启）
- 每次修改都会写审计表；出问题可以先点「备份数据库」留档
注意：角色正在对局时不要改余额，结算时可能被覆盖。

【怎么关】
先退出游戏，再在任务管理器里结束 RichOnline.Server.exe。
（直接关掉最小化的服务端命令行窗口也可以。）

【目录说明】
RnClient.exe        客户端主程序
online-client\      本地连接配置（local.kpd，指向 127.0.0.1）
server\             服务端
  RichOnline.Server.exe
  scripts\          Lua 规则（179 个模块）
  config\resources\ 从客户端导出的 KPD / EMP 资源
  data\             账号数据库与运行配置
server\logs\        每次启动的运行日志（native-<pid>.jsonl）
